二、事件接口（gen/astroEvents.ts，@experimental）
------------------------------------------------
共同字段：
  id: string            事件 id
  kind: 事件类型
  atYear: number        发生年份（确定性，来自种子 + 天象/地质流）
  bodyId?: string       关联天体（行星/卫星/恒星）
  distanceLy?: number   关联恒星的距离（超新星等）
  severity: 0-3         0 天象 / 1 显著 / 2 灾变 / 3 灭绝级
  affects: string[]     影响层：sky / climate / ecology / society / religion / tech
  text: string          编年史用一句话
  data?: Record<string, number|string>  预留（如辐射剂量、亮星视星等）

预留函数（现在返回空 / null）：
  celestialEventsOf(world): CelestialEvent[]
  nextCelestialEvent(world, afterYear): CelestialEvent | null
  supernovaImpact(distanceLy, mass): { severity, radDose, skyMag, dustWinterYears } | null

三、事件清单（v1 只留接口；打 ✅ 的是以后优先做）
-------------------------------------------------
✅ 超新星爆发       邻近 >8 M☉ 恒星到寿命 / 极低概率随机
                   影响：夜空亮度、辐射冲击、尘埃冬天、宗教/天象、技术（同位素/遗迹观测）
                   距离门槛：<30 ly 严重、30-100 ly 显著、>100 ly 只当天象
                   接口：supernovaImpact(distanceLy, mass)
✅ 恒星超级耀斑/CME 低质量恒星（M/K）为主
                   影响：电网/通信/卫星（技术层）、极光、天象
✅ 大彗星 / 流星雨  轨道周期
                   影响：天象、宗教、历法、民间恐慌
✅ 近地天体擦过    撞击率 / 小行星带
                   影响：恐慌、宗教、技术（防御）、可能触发陨击
✅ 小冰期 / 火山冬天 超新星尘埃、地质活跃度、恒星活动极小期
                   影响：气候、农业、人口、动乱（不改地形；地质事件可另写地形）
◻ 伽马射线暴       极低概率、定向
                   影响：生态/人口（灭绝级阈值）；先只留类型
◻ 地磁倒转/漂移    地质活跃度 + 时间
                   影响：导航、磁暴、极光；先只留类型
◻ 双星互食 / 凌日 / 掩星  双星或卫星构型
                   影响：天象、历法、宗教（已有部分 omen 覆盖）
◻ 行星际会合窗口   轨道共振
                   影响：航行机会（行星际接口用）
◻ 极光大规模出现、黄道光、彗尾指向变化 等纯视觉事件（低成本，可后补）

四、地表模板（gen/surfaceTemplates.ts，7 个）
--------------------------------------------
每个模板 = 地表参数默认值 + 物质状态说明 + 期望大气：
  earth    地球型    液态水 + N2/O2 气；可呼吸；温带
  ocean    海洋型    几乎全海，液态水；湿润
  arid     干旱型    少量液态水/盐湖，CO2 气；陆地为主
  ice      冰封型    水冰/干冰，稀薄 N2 气；低温
  volcanic 火山型    熔岩/硫化物液滴，SO2 气；无水
  barren   荒芜型    无水无冰，岩石尘埃；近真空
  airless  无大气型  无水无冰、无大气；昼夜温差极大；CO2 仅极区固体
注意：模板套用时要按该天体「实际温度/气压」重算相态（materials.phasesOf），
      温度/气压不支持时给提示或自动降级（如液态水模板套到 200 K 无水天体 → 改冰盖/无）。

五、时间轴动画分级（按视角）
----------------------------
视角 A 星系完整视角（恒星 + 全部行星 + 卫星轨道）
  动：行星公转、卫星公转、掩食/合相高亮
  不动：国界/城市边界（只可叠加文明标记点，默认关）
视角 B 本星系视角（选中行星的局部系：行星 + 卫星）
  动：卫星公转 + 可叠加该行星的地表边界随时间变化（复用回放），行星自转/昼夜线
视角 C 地球仪视角（单颗行星 3D）
  动：地表贴图随年份（复用回放）、昼夜线、天空层（太阳/卫星/伴星方向与相位）
  建议增强：天空层用 positionAt(body, year) 驱动「太阳方向 + 月亮相位 + 伴星位置」，
            并渲染日食/月食/双星互食的阴影；母星/卫星在背景画成小圆盘（含轨道环）。
所有位置 = positionAt(node, year)（开普勒解，确定性），不写存档、不改生成。
